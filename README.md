# Voice Lab

Two small signal-processing projects about human voice, in Python and JavaScript.

1. [`classifier/`](classifier): a trained spoken-digit classifier (MFCC + SVM), 80.8% accuracy on speakers it never saw.
2. [`webapp/`](webapp): a live microphone spectrogram with pitch tracking and voiced/unvoiced detection, running fully in the browser.

Follow-up to [af-speech-analyzer](https://github.com/atabeeeeee385-code/af-speech-analyzer). Built with help from an AI assistant for code and structure; I worked through the DSP ideas to understand them.

Dataset: Free Spoken Digit Dataset (CC BY-SA 4.0), not redistributed here.
